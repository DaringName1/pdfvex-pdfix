# Approved watched-folder workflows — October 12, 2026

F60 now has a native manager and connected workspace/command action. Users choose disjoint source/output folders, recursion, suggest-first or automatic mode, and an exact PDF-copy or supported literal-text recipe. Folder access, recipe execution and persistent consent are approved separately. Existing files form the initial baseline; only new or changed stable PDFs become eligible. The manager remembers versions, avoids output/source loops, processes jobs sequentially and saves new exclusive outputs with sealed source/output receipts. It does not grant other folders or hydrate skipped placeholders.

Consent and receipts share encrypted OS-protected, flushed storage. A missing first-run own consent file is treated as absent after checking the containing directory; existing files still require the full ordinary-path/identity guard. Interrupted queued/processing/publishing jobs become reviewable recovery records, and planned output hashes support reconciliation without duplicate overwrite. Pause/revoke invalidate current work and persist; the app can export receipts. Monitoring runs while PDFix is open.

Source discovery checks ordinary local Windows paths, links/reparse/recall flags, identity and a 15-second stability interval. A fixed Windows read-lease broker denies concurrent writes/deletion while snapshotting. Exact copies retain every source byte. Text extraction uses the existing fixed AppContainer operation for supported literal built-in-font text; unsupported extraction refuses the item. File/job/count/size/time limits are visible, and unsafe/partial/locked paths are reported.

Remaining: broader reviewed recipe composition and conversion/compression/form actions, disk-backed large sources, cloud/provider readiness handling, richer persistent grant/index cleanup, content-aware conflict/duplicate policies, actual crash/disk-full/lock/hostile-path/corpus/performance/UI/security acceptance. Encryption availability failure disables automation; no plain-text consent or unrestricted parser fallback is used. The targeted fixture receipt separately records exactly which approval/copy/recovery cases ran.
