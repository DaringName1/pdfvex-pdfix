# PDF reader usability additions — October 7, 2026

Implemented and compiled; current runtime acceptance is pending. No app, browser, engine, broker, provider, printer or installer tests were run. The running application was not restarted.

- **R40 / F01 — PDF artwork fullscreen:** reader button, Actions entry and Ctrl Shift Enter; hides application and reader chrome, comments/navigation panels and measurement/selection UI. Fits artwork to the screen, preserves the original layout through temporary styling, and snapshots the original physical page, fit/zoom, reading mode, scroll and keyboard focus. Reading-text view temporarily becomes artwork. Escape/F11 and a temporary auto-hiding exit button restore the previous view and the prior native fullscreen state. Entry/exit/reader cleanup serialize; external native fullscreen exit is handled. Modal dialogs must finish first. Documents, comments, recovery drafts and ledger data are not exported or rewritten by this view change.
- **F04 — Hand and pointer navigation:** H toggles the hand tool with page focus; drag or temporary middle-mouse drag pans. Ctrl + wheel zooms around the pointer; +/− zoom with page focus. Existing rendering, zoom and pixel limits apply. Wheel events coalesce and serialize, stale anchors after view/fullscreen transitions are ignored, and interaction suspends for normal measurement/rectangle/interactive-field/dialog work. Text selection remains the default. Fullscreen supports navigation without exposing its surrounding panels.
- **F02 — Reading density:** Settings offers persistent Compact/Comfortable document spacing. Compact remains the default. Comfortable gives larger controls and spacing without altering document content or paper dimensions; existing accessibility scaling remains separate.

Root integrated the delegated canvas-navigation module. Syntax checks passed for the six changed/new JavaScript entry modules; Vite compilation passed with 250 modules. Current renderer: index-BQW-n49K.js; stylesheet: index-DPcl7RKb.css. Existing large-chunk warning remains.
