# Local text statistics progress

Implemented the shared, local statistics engine and workspace in `src/text-statistics.js` and `src/text-statistics-workspace.js`. Word counts use `Intl.Segmenter` with `word` granularity when available; characters use grapheme clusters. A Unicode letter/number matching fallback and Unicode code point character fallback are identified in the UI. Spaces remain in the “with spaces” count, and whitespace graphemes are excluded from the “without spaces” count. Counting yields after bounded batches and supports cancellation. Each supplied chunk must be a complete semantic unit, such as an editor paragraph or PDF page, to avoid splitting a word at an arbitrary boundary.

The editor integration in `src/document-statistics.js` adds selection and whole-document scopes, paragraph counts for nonempty editable body text blocks, and the editor's one visible sheet. That sheet is explicitly labelled as an editor sheet; exported physical pagination is unavailable until export preview. The panel can include the current header and footer text once in whole-document statistics. Editable table cell text is included; images, non-text objects, and header/footer text by default are excluded. Selection is captured from the editor's body document and guarded by its revision. Source formats require an explicit “Count source as prose” checkbox; their normal footer does not claim a prose word count.

For PDF integration, construct `new TextStatisticsWorkspace(host, {scopes, getScope})`. `scopes` is an array such as `[{id:'selection',label:'Selection'},{id:'current-page',label:'Current page'},{id:'document',label:'Document'}]`. `getScope(id, {signal, options})` returns `{chunks, pageCount, pageCountLabel, notes}`. `chunks` is an async iterator of strings or `{text, paragraphs?}` objects. Yield one PDF page or smaller *complete* text units per chunk, check `signal` during extraction, and provide a physical `pageCount` only when known. Leave paragraphs unavailable unless extraction can identify actual paragraphs. Pass accurate notes on missing OCR, omitted non-text content, header/footer treatment, and table extraction; do not infer prose from code or inaccessible image text. The workspace cancels stale scans and displays partial progress.

Verification requested for this coding pass is limited to source syntax and compilation. Runtime, UI, PDF, and fixture testing are intentionally deferred.
