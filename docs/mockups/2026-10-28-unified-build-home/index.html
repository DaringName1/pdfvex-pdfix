Unified Build: same tabs on PDFs and documents, Home = all text tools

Owner decisions, October 28, 2026 (mockup by Claude, reviewed with the owner). This shows the idea, not exact pixels: Codex may adjust spacing, sizes and styling so it looks right in the real app.
  1. Same tabs, same order, on PDF and new-document Build: File, Home, Insert, Edit, Review, Fill & Sign, Pages, View, Protect, Measure, Export. Review = PDF Comment + document Review; Pages = PDF Pages + document Layout. A tab that can't work for the file type stays in place, greyed out with a short reason (Measure on documents).
  2. Home = every text tool, the same on both: Style; Font (font, size, B, I, U, S, superscript, subscript, color, highlight, clear style); Paragraph (bullets, numbering, indents, Spacing menu with line spacing, space before/after, first line, right indent; four alignments); Find. On a PDF they apply to text typed on the page (e.g. a school worksheet).
  3. All other tabs keep the current big icon + name tiles in labelled groups (as the PDF Pages tab looks now). Home keeps the same toolbar height so the page doesn't jump.
  4. The PDF's current Home tools move to Edit, Review, Fill & Sign and Pages.
  5. No "Name" box in the tab row: double-click the name at the top left to rename.
  6. Quick edit stays without tabs.
Try: switch PDF / New document, click tabs, double-click the name, click Spacing.
