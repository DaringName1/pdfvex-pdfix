# PDFix everyday test checklist

Use your own files where you can (keep a copy of anything important first). For each task, tick it or write one line:
what you did, what happened, and the file name. "It was confusing" is a useful note too.

Open the app: `app\PDFix.exe` in the newest folder under `releases`.

## Reading PDFs
- [ ] 1. Open a PDF from Home with **Open a file**. Scroll, zoom in and out, and go to a page by number.
- [ ] 2. Press **Ctrl+F**, search for a word, and step through the matches with **F3**.
- [ ] 3. Open a large drawing set (100+ pages). Note how long it takes and whether anything looks wrong or blank.
- [ ] 4. Printer check: follow [the Epson printing steps](PRINTER-ACCEPTANCE-2026-10-15.md) with the calibration page (output/pdf/pdfix-printer-calibration-letter.pdf). Measure the two rulers and the square with a real ruler and write the numbers down. Then print two pages of one of your own PDFs and check nothing is cut off.

## Filling and signing
- [ ] 5. Open a PDF form with **Fill and sign**, type into its fields, add a signature, save a copy, and reopen the copy.
- [ ] 6. On a PDF that is not a form, place your name and the date where a signature would go, and save.

## Marking up drawings
- [ ] 7. Open a drawing, add a note, an arrow and a revision cloud, save a copy, and reopen it.
- [ ] 8. Set the scale on a drawing and measure one length you know. Is the number right?

## Pages
- [ ] 9. **Fix or combine pages**: turn one page, move one, delete one, and save a new PDF.
- [ ] 10. Join two PDFs into one.
- [ ] 11. **Make a file smaller** on a big PDF. Compare the size and how the pictures look.

## Documents
- [ ] 12. **New document**: write a page with a heading, a list, a table and a photo. Save it (Ctrl+S).
- [ ] 13. Export that document as **PDF** and as **Word** (Export DOCX). Open the Word copy in Microsoft Word: does it look right?
- [ ] 14. Open a Word file you already have, change a sentence, and save.
- [ ] 15. Copy formatted text from Word or a web page and paste it into a PDFix document.
- [ ] 16. Close the app in the middle of typing (without saving), open it again: is your work still there?

## Other tools
- [ ] 17. **Image to PDF**: put three photos from your phone into one PDF.
- [ ] 18. **Make a scan searchable** on a scanned PDF, then search it for a word.
- [ ] 19. **Hide private information**: hide a name or number in a copy, then check it cannot be found by searching the copy.
- [ ] 20. **Protect or unlock a PDF**: add a password, close it, open it again with the password.

## Overall
- [ ] 21. Was there any tool you could not find, or whose name did not say what it does?
- [ ] 22. Did the app ever freeze, close by itself, flash, or show a blank screen? When?
- [ ] 23. Any message you did not understand? Copy its words.

Send the notes back as they are; Claude and Codex will sort them into fixes.
