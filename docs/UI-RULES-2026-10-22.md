# PDFix UI rules: everything the owner has said (October 21–22, 2026)

New here? Read [OWNER-UI-VISION.md](OWNER-UI-VISION.md) first: the idea behind these rules and how the owner works.

The owner: "if the UI sucks the app sucks." The Build screens are the part that needs fixing most.
This list collects every UI rule and decision the owner has given, from the UI master summary (October 21),
the owner's answers and the mockup review (October 22). Details of each tab are in
[UI-LAYOUT-PLAN-2026-10-22.md](UI-LAYOUT-PLAN-2026-10-22.md); the reasons behind the October 21 rules are in
[UI-DIRECTION-2026-10-21.md](UI-DIRECTION-2026-10-21.md). The mockup is the "Final" page of
https://claude.ai/artifact/9Up2cNtgo9GvpmNpNoJqjZ (owner's account).

If something here and another document disagree, this list wins; tell the owner.

## 1. The big idea

1. Simple for beginners (the owner's dad, friends), powerful for professionals.
2. Keep how PDFix looks now: colours, green, calm feel. Fix how it **works**; do not restyle the app.
3. Borrow **how** other apps work, never copy their look. The apps the owner likes:
   - **Acrobat**: the main inspiration.
   - **Word**: the toolbar look and named groups.
   - **Fusion**: the drop-down under each group of tools.
   - **Bluebeam**: options that change with the tool, panels that close.
   - **Documents (Google Docs, Word)**: click anywhere on the page and type; drag and drop things.
   - **Google Docs toolbar**: borrow its **small buttons** for things used all the time, and its slim row for short screens
     (mockup H1, H2). The main toolbar stays the Word/Fusion look.
4. Before designing anything, look up how those apps do it and reread this list.

## 2. Look

1. The Word document editor screen (mockup screen E) is the model: modern, simple, an options panel on the side.
2. No big buttons in the tab row or the toolbar.
3. The toolbar looks like the Word editor's toolbar today:
   - plain buttons, with no box around a button or a group
   - a thin line between groups
   - the picked tool in light green
   - boxes only for lists such as font or size
4. Every Build tab looks the same: same tab row, same kind of toolbar.
5. Nothing cluttered. A tab never has a long row of drop-downs (the owner: "not like 8").
6. Works on a small laptop screen; messages never cover controls.
7. **The main toolbar is the Word/Fusion look** (owner, October 22): icons with their names, groups with the name and ▾ under
   them (mockup D, F1–F9). This is the default.
8. **Small Google Docs-style buttons for things used all the time:** small icon buttons for things used all the time (for example Undo, Redo, Zoom, Find, Print), added the
   Google Docs way: a small icon with its name on hover, no box, at the start of the toolbar or beside the tool they belong to. Only for actions people use constantly;
   everything else stays in its group.
9. **Short screens:** on short screens (about 800 px tall or less, such as 1366×768 laptops) the toolbar folds to the slim
   Google Docs-style row (small icons, names on hover; mockup H1, H2) so the page keeps its room. "Show names / Hide names"
   at the end of the toolbar also switches by hand.

## 3. Window parts (use these names)

Side rail → top bar → file tabs → tab bar → **toolbar** (the row under the tab names) → page area →
Options panel → right-edge panel bar → status bar.

## 4. Modes

1. Three modes for a PDF:
   - **View**: just reading. The View screen (mockup B) is good as it is.
   - **Quick edit**: signing, filling and marking up. The PDF's own text and pictures stay as they are. Its tools are the
     **same tools** as in the Comment and Fill & Sign tabs (same behaviour, same side panel, same defaults), never copies.
   - **Build**: changing the PDF itself, with every tool.
2. **PDFs open in Quick edit** (owner, October 22; this replaces "PDFs open in View"). Switch to View to just look.
   New documents and Word files open in Build. One click switches.
   Switching keeps the page, zoom, selection and unsaved changes. Full screen is separate.
3. The Word editor has View and Build.
4. **One mode button, not three** (owner, October 22; like Fusion's DESIGN ▾). It shows the mode you are in with its
   icon (for example "Quick edit ▾"). Clicking it opens a short list of the modes, each with one line saying what it
   is for; Ctrl+Shift+E also switches. The Word editor uses the same button with View and Build.

## 5. Tabs, groups and tools

1. **The whole app keeps every tool it has.** Nothing is removed.
2. The Word editor keeps every tool it has today:
   - Row one: undo, redo, styles, bold, italic, underline, strike, superscript and subscript, highlight, font, size,
     colour, clear style, alignment.
   - Row two: bullets, numbering, indents, line spacing, space before and after, first line, right indent, Find.
3. Build tabs: Home, View, Comment, Edit, Fill & Sign, Pages, Protect, Measure, Export.
4. Each tab's toolbar shows its **most-used tools**, in a few groups (usually 3, at most 4). Each tool is an icon
   with a short name.
5. **Like Fusion**: each group has its name with ▾ **under** the group. That drop-down lists **every** tool in the
   group, with the rarely used ones last, under "Less used".
6. **Every tool is already there.** Nobody has to add tools themselves. The 1% who need a rare tool find it in its
   group's drop-down. The team may move a tool onto the toolbar in a later version if many people use it.
7. **Names are not fixed.** Use the clearest name there is, and one name per tool everywhere (menus, search, Home,
   All tools).
8. One tool, one place: menus, shortcuts, Home and search all open the same tool, never a second copy of it.

## 6. How tools work

1. Tools work **on the open document**: no pop-up window holding a second small copy, no chains of dialogs, no
   dialog for simple things. Fill and sign, Edit PDF text, Redact and Extract a table all work on the main page.
2. Picking a tool opens its options in the **Options panel** on the right. × or Escape closes it.
3. Tools offer their ways of working, each with a short description:
   - Text: Click to type / Edit existing / Text box
   - Select: text / objects / area
   - Draw: line / connected lines / freehand / shapes (separate lines never join on their own)
   - Measure: distance / area / angle / perimeter / count
   - Image: insert / replace / crop
   - Table: insert / edit / extract
4. Settings for a selected thing show only while it is selected (like Word's picture tools).
5. Protect lets you pick: a password to open only, limits only, or both.
6. Undo and Redo work the same everywhere and sit next to the file name.
7. Clear feedback: visible focus, selection, the tool in use and loading.
8. Keyboard shortcuts.
9. The status bar shows page, zoom, tool, what is selected, and whether the work is saved.

## 7. The side panel and tool defaults (owner, October 22)

**Every tool works the moment you pick it.** Its default is set up so most people never touch the panel: pick the tool,
use the mouse on the page, press Enter if it needs finishing, done. Nobody should sit there for 10 minutes per tool.
The panel is only for changing things. (Mockup screens D and G.)

**Mouse first, Enter to finish, Esc to stop:**

| Tool | What the default does |
|---|---|
| Highlight, Underline, Strike out | Drag across words; let go and it is done (yellow highlight, blue underline, red strike) |
| Text / Type on page | Click anywhere and type; click outside or Esc when done |
| Note, Comment | Click where it goes, type, Enter saves |
| Draw | Drag to draw freehand (red, 2 pt); Connected lines: click points, Enter finishes |
| Shapes | Drag a rectangle (red line, no fill) |
| Stamp, Date, Check mark, Initials | Click where it goes (Approved stamp, today's date, a tick) |
| Sign | Click where it goes; your saved signature is placed (first time: type your name, Enter) |
| Fill form | Click a box and type; Tab goes to the next box; Enter finishes |
| Image | Click where it goes and pick the picture, or drop a picture on the page |
| Select | Click a thing, or drag a box around several |
| Link | Drag over the words, type the address, Enter |
| Distance / Area / Perimeter / Count | Click the points; Enter finishes; uses the sheet's scale |
| Redact | Drag over what must go; the panel's Apply redactions button removes it |
| Password, Compress, Make searchable, Save as Word, Page numbers, Crop page | The panel opens with the default already picked; Enter (or its one button) does it |

**Tools stay on.** Marking tools (highlight, draw, shapes, stamps, notes, measure) stay on after each use until Esc or another
tool, unlike Acrobat, which switches them off after every mark. "Keep … on after each use" in the panel can turn this off.

**The Options panel looks the same for every tool**, top to bottom:

1. **Top:** the tool's icon and name, × to close (Esc too).
2. **How to use it:** one short line, mouse first (for example "Drag across words. Let go and they are highlighted.").
3. **HOW:** the tool's ways of working as choices, the default already picked.
4. **SETTINGS:** the two or three settings people change (colour, size), already set to the default.
5. **More settings:** everything else, folded away.
6. **Bottom (always the same place):**
   - Keep this tool on after each use
   - **Save as my default** and **Reset** (as in Bluebeam)
   - the one action button, only for tools that need one (Apply redactions, Protect, Compress…)
   - "Your original is unchanged until you save a copy."

**Change the default of each tool.** Save as my default makes the tool start with the current settings every time, for this
person. Reset goes back to the PDFix default. Changing a setting with something selected changes that thing; with nothing
selected it changes what the tool makes next. Settings has a Tool defaults list to see and reset them all.

**The panel itself:** about 290 px wide, beside the page (never on top of it), the same place for every tool, resizable and closable.
Long explanations go in More settings or help, not in the panel.

**The other side areas:**
- **Left side rail:** logo; Home, Files, Favorites, All tools, Ask about files; Settings & privacy at the bottom.
  It is wide with names on Home and narrow with icons only when a document is open (names show on hover).
- **Right-edge panel bar:** page thumbnails, bookmarks, comments, attachments, layers. One click opens or closes each; the
  Options panel sits to the left of it.

## 8. Working on the page, like a document

1. Type anywhere on the page: with Text or Type on page picked, **click** anywhere and type; with any other tool or none,
   **double-click** anywhere to type (owner, October 22). A single click never makes a text box by itself.
2. Drag things on the page to move them: text, pictures, stamps, signatures, notes, shapes.
3. Drop pictures or files from Windows onto the page to put them there; drop PDFs to add their pages.
4. The page shows where a drop will land, and Undo takes any move or drop back.
5. In View nothing moves; View is just for looking.

## 9. Taken from Acrobat

1. Every tool is also in one All tools list (All tools in the side rail).
2. Find, Save a copy, Print and Share always sit top right.
3. A slim bar of panels on the right edge: page thumbnails, bookmarks, comments, attachments, layers. Each opens
   beside the page and closes again.
4. Panels are optional and resizable. Closing a panel never takes away what it does.

## 10. Home

1. Keep Home as it is now: the mockup's Home and the app's Home.
2. Small and useful:
   - Open and New
   - recent files with previews, and pinned files
   - a few common tasks
   - one search for files, tools and help
3. Recent-file previews are a setting: Off / Show when I hover (default) / Always.

## 11. Not OK (rejected)

- Big buttons in the tab row or toolbar; a box around every button or group.
- A giant toolbar of equal icons.
- Drop-downs piled at the far right, away from their tools.
- Many drop-downs in one tab, or a cluttered tab.
- Removing tools, or hiding tools so that people have to add them back themselves.
- Tools that need setting up before they work, or that switch themselves off after every use.
- A different panel layout for each tool.
- Floating toolbars over the page (including Acrobat's floating quick-tools bar).
- A pop-up with a second copy of the document; chains of dialogs.
- Separate full-screen editors for related tools.
- Duplicate tools with different names.
- Toolbars that move around; deep nested menus.
- A dashboard of colourful cards.
- Copying the look of Acrobat, Word, Fusion or Bluebeam.
- Forced AI, accounts, ads or paywalls. AI is optional (local or user-chosen) and never a permanent sidebar.
- Restyling the app away from today's PDFix look.

## 12. Mockups and reviews

1. Show the whole screen at real size, with the real number of buttons the app will have.
2. One screen per tab. Never cram many tabs into one picture.
3. Clickable when it helps (the Final page screens C, D and F1 to F9 are).
4. A UI change is checked by eye on screenshots before it is called done.

## 13. Later (after the beta)

- Project groups for related files, beside normal tabs.
- Workspaces that share one PDF core and are not separate apps: Documents & Publishing, Engineering, Science & Data,
  Research.
- Saved layouts, saved presets, a larger command search.

## 14. Final (owner, October 22)

The owner called this list and the Final page of the mockup the final UI changes. Stick to these rules; when unsure, ask.
