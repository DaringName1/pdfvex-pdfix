# Reviewed PDF table extraction — 2026-10-04

Workspaces, the action finder and PDF reader now offer Extract a table. The workspace retains the opened source document, shows its actual physical-page artwork and lets the user drag a region or enter percentages. Equal or custom row/column breaks define a bounded 100-row by 32-column grid. Source text is read from bounded PDF.js text content and DOM word rectangles; a selected scan region can use existing local English OCR with bounded word boxes and confidence values. Row breaks can be suggested from word lines. No original PDF content is changed.

Word centers assign cells; crossed grid boundaries and uncertain OCR are highlighted. The user can correct every cell, review paged rows and confirm the table against the original before CSV saving. Changing the region/page/grid makes the previous result stale. Rebuilding explicitly replaces corrections. Unsaved data remains in memory; close/departure requires saving or an explicit second close to discard. Cancellation stops owned rendering, streamed text and OCR work without destroying the reader's shared document.

Native CSV saving validates the exact source SHA, page, mode, region, reviewed state and rectangular text matrix. Limits are 10,000 UTF-16 characters per cell, 500,000 total characters and 2 MiB CSV output. UTF-8 BOM, quoted cells, doubled quotes and CRLF rows preserve ordinary CSV text. Formula-looking or initial tab/newline values receive an apostrophe and the saved result reports that count. Saving uses a native picker and exclusive SHA-verified copy. Contained source inspection refuses encrypted PDFs; source identity is checked before and after filename picking. Reader copying restrictions disable extraction.

Remaining work includes persistent correction recovery, merged-cell/irregular-table reconstruction, handwriting, rotated-text OCR, more languages, XLSX export and real-file extraction/round-trip acceptance. This advances the broad table-extraction requirement without closing its full acceptance checkbox. No application, feature worker, OCR engine, native engine or runtime tests were launched. Source syntax and renderer/native-package compilation passed; these do not establish extraction accuracy.
