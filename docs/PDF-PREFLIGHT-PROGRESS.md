# Practical PDF preflight source implementation

Source implementation toward A05/F29/F40 adds inspection-only practical profiles, source-bound evidence and bounded contained processing. The implementation does not claim PDF/X, PDF/A or complete commercial preflight acceptance.

- `desktop/pdf-preflight-codec.cjs`: source parsing, bounded object/page traversal, actual inherited MediaBox/CropBox and declared/default BleedBox/TrimBox/ArtBox geometry, page UserUnit/rotation and explicit box bleed measurement. Inventories declared page and invoked Form resources, local embedded font program presence, image dimensions/bit depth, transparency declarations, color families and output-intent ICC presence.
- Image placements come from actual `q`/`Q`/`cm`/`Do` interpretation, with nested Form Matrix concatenation, per-page UserUnit, resource scoping and repeated-use evidence. Effective dpi includes axis values and a conservative singular-value minimum that accounts for shear. Degenerate/unresolved placements never receive a passing resolution.
- `desktop/pdf-preflight-validation.cjs`: three fixed versioned practical profiles; strict inert report/source/shape validation; independently derived findings and counts from reported evidence; a canonical inventory SHA-256 seal. A seal binds a report to bytes/profile but does not certify correctness or standards compliance.
- `desktop/pdf-preflight-service.cjs`: `ContainedServiceContext` subclass, exact opened-source validation, `preflight-inspect`, cancellation/discard/disposal through the existing containment lifecycle. No rewriting or save operation.
- `src/pdf-preflight-workspace.js/.css`: actual profile thresholds, physical-page findings/jumps, exact source/inventory identity, page/item evidence, paginated lists and explicit unresolved/unsupported scope. No automatic fixes.

Engine API: `require('./pdf-preflight-codec.cjs').inspect(bytes, {profileId})`. Supported IDs: `practical-print-v1` (default), `press-review-v1`, `screen-review-v1`. Service API: `PdfPreflightService.inspect(sourceId, source, profileId)` plus inherited `cancel`, `discard`, `status`, `dispose`. Renderer bridge APIs: `inspectPdfPreflight(sourceId, profileId)` (adds a main-process export token), `savePdfPreflightReport(sourceId, exportToken)` (saves the exact main-retained report), `cancelPdfPreflight(sourceId)`, `discardPdfPreflight(sourceId)`, plus existing `editorGuard`. Closing/departure is refused during the native Save dialog.

Bounded work: 100 MiB source, 500 pages, 100,000 indirect objects, 300,000 object visits, 64 object/graphics-state levels, 24 Form levels, 10,000 evidence items/category, 4 MiB decoded program, 32 MiB total decoded program work, 1,000,000 content tokens and 20,000 program invocations. The entire report is additionally bounded to 280,000 JSON nodes, 80 JSON levels and 16 MiB, below the containment reviver's existing 300,000-node budget; independent evidence-category maxima cannot all fit the aggregate report. Images, font programs and ICC payloads are not decoded. External resources and PDF actions are never executed or fetched.

Unsupported or unresolved: inline images stop the affected program; external streams/DecodeParms, unknown operators, malformed resources and cyclic Form programs report unresolved coverage. Annotation/widget appearances, Type 3 glyph content, pattern programs, shading internals, optional-content visibility and uninvoked Forms are not traversed for placement. Font glyph coverage, Unicode/font license checks, actual render fidelity, ICC payload validation, press suitability, spot separation/overprint/ink coverage, bleed artwork coverage and standards-specific conformance remain unverified. No passing result is inferred for those checks.

Acceptance status: source implementation only. Per user instruction, validation is restricted to syntax/compilation; no runtime execution, PDF processing, document fixtures, UI operation or tests were performed. Native containment and representative-document/visual acceptance remain pending.


Root integration and compilation completed with 288 modules. Main/preload/contained engine/reader/action palette/lifecycle and source-bound report export are wired. No runtime/document/UI/security/standards acceptance was run. See [compiled checkpoint](PREFLIGHT-FORMS-CODING-2026-10-09.md).
