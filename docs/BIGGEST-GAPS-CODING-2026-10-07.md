## Integration and lifecycle

Eight fixed engine operations are added: `table-xlsx-write`, `batch-pdf-text`, `bookmark-inspect`, `bookmark-build`, `decoration-build`, `attachment-inspect`, `attachment-select` and `link-resolve`. Child codecs are imported only by the fixed engine entry. Main-process services import bounded inert validators rather than PDF/Office parsing codecs. All adopted families share the existing two-job containment limit, pinned runtime/broker checks and fixed staging slots.

Cancellation waits for observed contained process termination. Sealed decoration/bookmark/attachment previews are cleared on cancellation/discard/disposal. Renderer loss recreates these services only after successful disposal, with prior runtime/staging configuration retained; unsafe cleanup leaves the service closed. Save handlers use the current service instance after restart. Table export cancellation covers security preflight, writer preparation and the save-picker fence; once an exclusive copy is being written, cancellation reports that saving must finish.

Native and renderer Security Sandbox status include the added families. The batch workspace appears in Workspaces and Actions, with close/departure cleanup. No new banners or extra PDF headers were added. Existing development/release limitations remain visible in Settings and the feature ledger.
