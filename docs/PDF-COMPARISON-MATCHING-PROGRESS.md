# Drawing comparison page matching — October 7, 2026

Implemented in `src/pdf-comparison.js`, `src/pdf-comparison-matching.js`, and comparison CSS. Source syntax checks passed. Runtime tests and app launch remain deferred at the user's request; this is implemented source, not validated drawing equivalence.

- Page matching lives in one closed-by-default expandable section. Unplanned document comparisons start as independent manual page review. Automatic matching never silently accepts page-number alignment. Existing exact output page plans still drive staged comparisons and remain unchanged; a separately confirmed review mapping can override only the comparison's pairing.
- Suggestion input is local permitted selectable text, PDF.js viewport dimensions (including intrinsic rotation and user units), and a white-background artwork raster with a maximum 128-pixel edge. Up to 100 total original pages and 100 compared pages are inspected sequentially, under a two-minute overall limit and 12-second individual awaits. Text streams stop at 5,000 items or 20,000 characters; matching retains bounded tokens and 256 artwork ink tiles, not page rasters. Restricted-copy sources skip text analysis. Larger sets retain manual mapping up to the reader's existing 500-page/document bound.
- Similarity combines bounded text overlap, tile-level artwork similarity and dimensions. There is no positional-index bonus. Strong suggestions require a score of at least 82% and reciprocal uniqueness margins of at least 4%; competing/repeated sheets remain uncertain. Scores are heuristics rather than probability estimates. Sparse blank pages receive no useful evidence, and shared title blocks, revisions, crop changes or differently rotated sheets can still need correction. No inference proves identical drawings.
- Each compared physical page has a source/page choice or explicit unmatched status. Twenty-five rows display at a time. Users can inspect a draft pair, correct its original physical page, leave it unmatched, restore an exact source page plan, and then explicitly confirm the reviewed mapping. Invalid page numbers are rejected. Duplicate original choices are preserved only after explicit user confirmation. Suggestions and mapping edits leave the active comparison unchanged until confirmation.
- Confirmed linked navigation, side-by-side changes, drawing-overlay source identity and whole-document checks follow the reviewed mapping. Unmatched compared pages show only their artwork; no last or same-index original page is substituted, and difference/overlay results are unavailable. Reports distinguish unmatched compared pages from detected differences and count omitted originals when their page counts are known. Unopened sources make omission counts explicitly incomplete.
- Existing review-resolution difference, overlay controls, original document buffers, page plans and PDF.js rendering limits are preserved. Matching cancellation rejects pending waits and cancels rendering tasks; current mapping and documents remain intact. No new dependencies, network access, native changes or saved-document mutation were added. Session-only maps are cleared on comparison close.

Remaining: runtime checks for reorder/insert/delete/duplicate-sheet cases, scanned drawings, protected documents, cancellation and resize behavior, and real Bluebeam drawing sets. Persistent matching projects and exact drawing semantic comparison are separate future work.
